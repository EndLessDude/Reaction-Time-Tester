# Sitting-BlueMate

## Description:
This project is a 3D design of a Blue among us character that I made on OnShape. My design is unique as unlike most designs of among us characters this one is completely flat at the bottom so it can be placed on your desk like it's sitting there.

Software:
For this design I used OnShape. OnShape is a beginer friendly cad software that you can run on your browser.

Tools used:
- Sketch
- Extrude
- Revolve
- Fillet
- Line
- Conic
- Corner Rectangle
